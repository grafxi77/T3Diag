# Contributing to T3Diag

Thank you for your interest in T3Diag.

## Development Rules

- Follow PEP 8.
- Use type hints.
- Document all public functions.
- Write unit tests for new functionality.
- Keep protocol and vehicle logic separated.
- Do not commit undocumented protocol assumptions.
- Document all hardware findings before implementation.

## Git Workflow

- Never commit directly to `main`.
- Develop new features in feature branches.
- Keep commits small and meaningful.
- Update documentation together with code.
